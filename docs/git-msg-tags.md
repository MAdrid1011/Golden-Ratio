# Git Commit Message Tags

- `[core]`: Changes core runtime behavior or project functionality.
- `[feat]`: Adds a user-facing capability.
- `[bugfix]`: Corrects unintended behavior.
- `[perf]`: Improves performance without changing intended behavior.
- `[build]`: Changes dependencies, packaging, or build configuration.
- `[docs]`: Changes documentation only.
- `[tests]`: Changes tests only.
- `[refactor]`: Restructures code without changing intended behavior.
- `[chore]`: Performs repository maintenance not covered above.
